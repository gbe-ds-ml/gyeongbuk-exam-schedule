# 경북 고등학교 해커톤 참가 여건 분석

경상북도 고등학교 1·2학년의 2026.12.12.(토)~12.13.(일) 해커톤 참여 여건을 나이스 교육정보 개방 포털 `schoolInfo` · `SchoolSchedule` API로 검토하는 모바일 웹입니다.

## 열기

GitHub Pages에서 `gh-pages` 브랜치의 `index.html`을 배포합니다.

- https://gbe-ds-ml.github.io/gyeongbuk-exam-schedule/

사이트에서 개인 나이스 API 인증키를 입력한 후 '전체 학교 분석 시작'을 선택합니다. 브라우저의 교차 출처 요청 제한(CORS)이 있을 경우 직접 조회가 실패할 수 있습니다.

## 2026년 12월 12~13일 해커톤 분류 원칙

- **참여 가능:** 12월 11일까지 1·2학년 2차 정기고사가 종료된 기록이 확인되거나, 조회된 학사일정에서 행사 및 직후 평일 시험 충돌이 발견되지 않은 학년. 종료일 명시가 없으면 판정 근거에 **잠정** 표시.
- **시험기간 겹침:** 12월 12~13일이 명시된 정기고사 기간 안에 있거나 해당 학년의 시험일이 주말 양쪽에 연속하여 등록된 경우.
- **시험 직전:** 12월 14~18일 정기고사 일정이 확인된 학년.
- **확인 필요:** 학년 누락·모호한 행사명·학사일정 공백 등 검증 불가능한 경우.
- **조회 실패:** API 오류 또는 응답 실패. 참여 가능으로 간주하지 않음.
- **일부 학년 가능:** 1·2학년 중 한 학년의 판정만 참여 가능인 학교. 어느 학년이 가능한지 학교 상세에서 별도 표시.

첫 번째 요약 카드에 **참여 가능(전체·일부 학년 포함) 학교 수**를 표시하며, '참여 가능 학교 보기' 버튼으로 즉시 필터링할 수 있습니다. 학교명을 클릭하면 학년별 근거와 원문 학사일정을 볼 수 있고 CSV로 내려받을 수 있습니다.

## 유의사항

1. 판정은 **등록된 나이스 학사일정**에 기반한 운영상 추정이며 참가 허가가 아닙니다.
2. 12월 11일이 마지막으로 등록된 시험일이라도 종료일이 명시되어 있지 않으면 **참여 가능(잠정)**으로 표기합니다. 12월 14일 이후 시험이 누락되었을 수 있으므로 학교 확인이 필요합니다.
3. 한 학년만 참여 가능한 학교는 전체 참가가 가능한 학교와 구분합니다.
4. API 인증키를 리포지토리 소스에 직접 게시하지 않습니다. 개인 입력 키는 해당 기기의 브라우저 저장소를 사용합니다.
5. API 호출에 CORS 제한이 있으면 정적 GitHub Pages만으로 해결되지 않으며 별도 중계 서버가 필요합니다.
