# 경북 고등학교 해커톤 참가 여건 분석

2026년 12월 12일(토)~13일(일) 해커톤 참가를 위해 경상북도 고등학교 1·2학년의 2차 정기고사 일정을 분석하는 모바일 웹입니다.

## 배포

- 정적 웹: `gh-pages/index.html`
- GitHub Pages: https://gbe-ds-ml.github.io/gyeongbuk-exam-schedule/
- 사용 방법: 나이스 API 인증키를 브라우저에서 입력하고 ‘전체 학교 분석 시작’을 선택합니다.

## 학년별 판정 기준 (2026년)

| 유형 | 기준 | 해커톤 참가 여건 |
| --- | --- | --- |
| 10일까지 종료 | 12월 10일 또는 그 이전 시험 종료 | 참여 가능 |
| 11일 종료 | 12월 11일에 시험 종료 | 참여 가능 |
| 시험기간 겹침 | 정기고사 기간이 12월 12~13일 주말 포함 | 참여 어려움 |
| 시험 직전 | 12월 14~18일 정기고사 일정 | 참여 어려움 |
| 기타 참여 가능(잠정) | 명확한 시험 충돌 근거가 없거나 이후 시험이 멀리 있음 | 학교 확인 권장 |
| 확인 필요 | 시작일만 확인되고 종료일 미상, 행사 후 시험의 대상 학년 미기재, 일정 누락 등 | 학교 확인 필요 |

* 12월 8~11일 시험 후 12월 14일 이후 시험 기록이 없다면 ‘11일 종료’로 분류합니다.
* 마지막으로 입력된 시험일만 있는 경우 종료일 확정이 아니므로 판정 근거에 ‘잠정’을 표시합니다.
* 명시적 종료일이 없는 시험의 시작일만 등록된 경우에는 종료로 추정하지 않습니다.
* 두 학년 모두 가능하면 학교 전체 가능으로 분류하며, 한 학년만 가능하면 ‘일부 학년 가능’으로 구분합니다.

## 화면 기능

- ‘12/10까지 종료’와 ‘12/11 종료’ 각각 별도 요약 카드 및 필터
- ‘참여 가능 전체’ 버튼으로 10일까지 종료 / 11일 종료 / 기타 참여 가능 / 일부 학년 가능을 함께 조회
- 학교명 클릭 시 1·2학년별 근거와 나이스 학사일정 원문
- 학교명·시군 검색, 학년별 필터, CSV 다운로드

## 제한 사항

- 나이스 학사일정은 학교 입력 자료이므로 모든 정기고사 일정이 정확히 기록되었다고 보장할 수 없습니다. 참가 결정 전 해당 학교 확인이 필요합니다.
- 인증키는 공개 저장소에 넣지 않으며 사용자 브라우저 저장소에 보관합니다.
- GitHub Pages의 브라우저 호출은 나이스 API 서버의 CORS 정책 영향을 받습니다. CORS가 차단되면 별도 중계가 필요합니다.
