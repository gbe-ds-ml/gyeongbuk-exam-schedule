# 경북 고등학교 2차 정기고사 기간 분석

2026년 12월 12일(토)~13일(일)이 경상북도 고등학교 1·2학년 2차 정기고사 기간에 포함되는지 나이스 교육정보 개방 포털 학사일정 API로 검토하는 모바일 웹입니다.

## 기능
- 경북 고등학교 목록 및 2026.11.24.~12.23. 학사일정 조회
- 1·2학년별 시험기간 포함/미포함/확인 필요/조회 실패 판정
- 학교명 클릭 시 학사일정 원문 표시
- 학교명 검색, 판정 필터, CSV 다운로드

## 배포
정적 웹 파일은 `gh-pages` 브랜치의 `index.html`에 있습니다. GitHub **Settings → Pages**에서 **Deploy from a branch / gh-pages / /(root)**로 설정하면 모바일 웹으로 접근할 수 있습니다.

## 주의
1. 공개 GitHub 저장소에 나이스 API 인증키를 커밋하지 않습니다. 사용자가 접속한 브라우저에서 입력합니다.
2. 모바일 웹에서 나이스 API 직접 호출이 CORS 정책에 의해 차단될 경우 별도 API 중계가 필요합니다. GitHub Pages만으로 CORS 차단을 해제할 수 없습니다.
3. '미포함'은 등록된 학사일정에서 중복 근거를 찾지 못한 결과이며, 학교별 공식 시험 일정의 부재를 보증하지 않습니다.
